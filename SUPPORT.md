# Support

For usage questions, check the relevant repository's README and documentation first.

- **Bug:** Open a bug report in the affected repository.
- **Feature idea:** Open a feature request.
- **Incorrect map data:** Use the geographic data correction template.
- **General discussion:** Use Discussions where enabled.
- **Security issue:** Follow [SECURITY.md](SECURITY.md) and report privately.

Mazo Maps is community-maintained; response times may vary. Please do not share passwords, access tokens, or sensitive location information in public posts.
