# Governance

Mazo Maps is an open-source project coordinated by its organization maintainers.

## Participation

Anyone may propose improvements through issues and pull requests. Contributions are evaluated for correctness, maintainability, data provenance, privacy, and license compatibility.

## Decision-making

Maintainers seek consensus where practical. Organization owners retain final responsibility for repository permissions, publication, security decisions, and resolving unresolved disputes. This policy does not guarantee voting rights or merge access.

## Review and transparency

Substantial technical or data-model changes should be discussed in a public issue or pull request before adoption when feasible. Sensitive security and conduct reports are handled privately.

## Maintainer access

Maintainer permissions are granted and revoked by organization owners based on demonstrated trust, contribution quality, and operational need. Permissions should follow least-privilege principles.

## Changes to governance

Propose governance changes via a pull request to this repository; organization owners approve final changes.
