# Contributing to Mazo Maps

Thank you for helping improve open mapping worldwide. Contributions may include code, documentation, bug reports, and geographic data corrections.

## Before contributing

1. Check existing issues and pull requests to avoid duplicates.
2. Open an issue for substantial changes before implementation.
3. Follow the target repository's setup instructions, style, and tests.
4. Keep pull requests focused; explain what changed and why.
5. Respect our [Code of Conduct](CODE_OF_CONDUCT.md).

## Geographic data contributions

- Provide a clear location and feature type, using coordinates when appropriate.
- Describe the existing information, proposed change, and evidence or provenance.
- Only submit data you have permission to contribute under the destination dataset's license.
- Do not copy proprietary map content or imagery without permission.
- Avoid exposing private addresses, sensitive facilities, personal information, or precise locations of vulnerable people.
- Geographic edits may require verification, license checks, and maintainer review before publication.

## Code contributions

- Prefer small, reviewable changes and clear commit messages.
- Add or update tests and documentation where relevant.
- Never commit credentials, tokens, or private data.
- Follow the repository's license and contribution requirements.

## Pull requests

Use the provided template, link related issues, and report how you verified your change. Maintainers may request revisions or decline contributions that cannot be verified or licensed appropriately.

## Questions

Use the relevant repository's Issues or Discussions, where enabled. For vulnerabilities, see [SECURITY.md](SECURITY.md), not public issues.
